# Protected areas

Do not change these unless the user explicitly asks for that specific change in this session. If a task seems to need it, stop and explain why.

| Area | Why it is protected | Do this instead |
| --- | --- | --- |
| `client/src/app/api/**` | Generated by ng-openapi-gen; hand edits are lost on the next generation | Change the API, then run `pnpm open-api-gen` (see `client-api.md`) |
| `server/Context/Migrations/**` (existing files) | They are already applied to a database with real data | Add a new migration with `dotnet ef migrations add` (see `server-data.md`) |
| Layering of the server projects and their `ProjectReference`s | The dependency direction is the architecture (see `server-architecture.md`) | Put code in the layer that already owns that concern |
| `server/API/Program.cs`: content root, client path, static files, HTTPS redirect, middleware order, auth policies | Production runs the published API from a different working directory and depends on these exact paths and this order | Add new registrations next to their group; leave the rest as is |
| `server/Context/Configuration/**` (`.env` lookup order, `EnvVars`) | The API, `dotnet ef`, the tests and the client dev scripts all rely on the same lookup | Add new variables through `EnvVars`, not a new mechanism |
| Authorization: `[Authorize]` attributes, policies, role names, client guards | Removing or loosening one exposes editor or admin actions | Ask first; a new role needs a policy and a guard (see `server-auth.md`) |
| `.github/workflows/**`, `.github/pull_request_template.md`, `CONTRIBUTING.md` | They define the merge gate for every contributor | Propose the change, do not make it as a side effect |
| `client/eslint.config.js`, `client/.prettierrc.json`, `client/.prettierignore`, `client/tsconfig*.json`, `client/angular.json` budgets | Loosening a rule or budget to make a check pass hides the problem | Fix the code; if a rule is really wrong, propose it separately |
| `client/pnpm-lock.yaml` | Only the package manager may write it | Change dependencies through `pnpm add` / `pnpm remove` |
| `.claude/**`, `CLAUDE.md` | These rules themselves | Propose changes to the rules; do not edit them to make a task fit |
| `.env`, any secret | Never read into the conversation or committed | Document new variables in `.env.example` |
